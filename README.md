# Income Tax Calculator

A simple Income Tax Calculator built using HTML and JavaScript.

## Features
- Enter annual income
- Calculate tax instantly
- Simple and beginner-friendly UI

## Technologies Used
- HTML
- JavaScript

## How to Run
1. Download or clone the project
2. Open `index.html` in your browser
