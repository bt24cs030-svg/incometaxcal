# Background Color Changer

A simple JavaScript project that changes the webpage background color when a button is clicked.

## Features
- Change background color dynamically
- Uses Event Delegation
- Beginner-friendly project

## Technologies Used
- HTML
- JavaScript

## How to Run
1. Download the project
2. Open `index.html` in your browser

## Project Demo
Click any color button to change the page background color.# backgroundcolorchange
